# Order Summary Feature Specification

- Purpose: Display a summary of a customer's pizza order.
- Inputs: Receive the ordered item name and quantity.
- Price: Calculate and display the total using orderTotal() from lib/order.dart.
- Interface: Show the item name, quantity, and total price in RM.
- Navigation: Include a back button that returns to the previous screen using Navigator.pop().
- Testing: Verify the order details and confirm that the total displays RM25.00 for the test order.
